# Стек и вёрстка фронтенда

## Язык и CSS
- **TypeScript обязателен** — не используй чистый JavaScript.
- **Современный CSS**: переменные (`--name`), вложенность, `clamp()`, `:has()`, контейнерные запросы. Размеры — в `rem` (исключения: бордеры `1px`, иконки/картинки).
- Не тащи CSS-фреймворк «на всё», если задачу решает современный CSS; для сложных компонентов бери готовую UI-библиотеку.

## Адаптивность
- **Медиа-запросы** обязательны: интерфейс работает и на ПК, и на мобильных.
- При слишком узком экране (уже минимального поддерживаемого) основной UI **скрывается**, показывается сообщение: «Ваш размер экрана `WxH` слишком маленький для работы с `<проект>`. Требуется минимум `<размер>`».
- Минимальный размер храни в одном месте (CSS-переменная или константа), не дублируй числа.

## Библиотеки
- Сначала ищи **готовую библиотеку** под задачу (UI-компоненты, таблицы, графики, иконки) и подключай её. Свои велосипеды — в последнюю очередь.
- Держи список зависимостей минимальным; проверяй совместимость с serverless-хостингом (размер бандла, отсутствие серверных зависимостей).

## Проверка
- Прогони все разрешения: широкий десктоп, ноутбук, планшет, мобильный и «ниже минимума» (сообщение).
- Убедись, что нет горизонтального скролла и «поехавшей» вёрстки на промежуточных ширинах.
