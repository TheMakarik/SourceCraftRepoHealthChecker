# Основная информация для старта фронтенда

### Основной стек для написания фронтенда

1) TypeScript - обязательно, используй его вместо чистого JS
2) Modern CSS - современный CSS прекрасно поддерживает переменные, условные операции и тд при верстке используй его, также используй rem
3) Адаптивная верстка - используй медиа запросы чтобы фронтенд работал как на ПК так и на мобильных устройствах, но убедись что при слишком узком (таком каких телефонов сча нету) размере, основной UI фронтенда должен скрываться, и должна быть надпись о том что Ваш размер экрана x*y слишком маленький для работы с <название проекта> требуется минимум <размер>

### Выбор фреймворка и библиотек
Попроси у вайбкодера ТЗ ввиде PDF (самого хакатона) а также изучи API 

Затем подумай, как лучше всего реализовать это
* Выбери фреймворк - любой, главное чтобы поддерживал typescript и имел хорошую базу для реализации этого проекта, а также минимальным 
* Изучи дизайн (попроси его у вайбкодера) и найди библиотеки которые могут тебе помочь главное использовать ИХ а не городить свои нерабочии костыли
* После этого для себя составь фрейворк и список библиотек

Учти что все будет хоститься в serverless yandex 

После этого выбери какой нибуть MCP для веба, и подклчи его (ты через Claude Code работаешь), попроси пользователя перезапустить тебя если это нужно для поддключения MCP

Затем придумай как создать компонентную архитектуру, где многие фронтенд элементы можно разделить на независимые компоненты чтобы над ними могли легко работать субагенты 

Только после этого приступай к работе, или выполни чисто по тз и проекту с дизайном или по запросам от вайбкодера
